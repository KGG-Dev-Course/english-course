# English for Software Developers

A daily English course for developers. The lessons are published on a blog, which reads them from this public repo.

- `lessons/NN-slug.md`: one lesson per file. The blog shows these and orders them by `NN`.
- `course.json`: the title, description and `totalLessons`, which drives the blog's progress bar. Keep `totalLessons` in sync with the curriculum.
- `PROMPT.md`: the curriculum and the writing rules for lessons.

To write a lesson, use the `/new-lesson` skill.
