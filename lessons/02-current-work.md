## Why this matters

"What are you working on?" is probably the question you hear most often at work. Your manager asks it, a teammate asks it in the kitchen, and a recruiter asks it in an interview. A clear answer shows that you understand your work and why it matters.

## The core skill

### Present continuous for work in progress

When a task is happening now, or during this week or sprint, use the present continuous: *am/is/are + verb-ing*.

```text
I'm working on the checkout page this sprint.
We're migrating our database from MySQL to PostgreSQL.
Priya is fixing the login bug.
```

Use the present simple for things that are always or usually true, like your role or your team's job:

```text
I work on the payments team. We handle all card transactions.
```

So: *I work on the payments team* (my job in general), but *I'm working on refunds* (my task right now).

### What, why and where you are

A good answer has three parts:

1. **What** the task is.
2. **Why** it matters: the user or business reason.
3. **Where** you are: your progress.

```text
I'm building a CSV export for the reports page.
A lot of customers asked for it, because they want to use the data in Excel.
The backend part is done, and now I'm working on the UI.
```

The "why" is the part people forget. It helps non-technical listeners, and it shows you understand the bigger picture.

### Talking about progress

Use simple, honest words for progress. Developers often say a task is "almost done" for a week. Be specific instead:

```text
The API is done, but I still need to write tests.
I'm about halfway through. I've finished the data model, and the endpoints are next.
I've just started, so I don't have an estimate yet.
```

*Just* + present perfect means "a very short time ago": *I've just started.*

### What's next

End with your next step. It shows that you have a plan.

```text
Next, I'm going to add pagination.
After that, I'll hand it over to QA.
```

Use *going to* for a plan you have already decided, and *will* for a decision or promise you make now.

## Useful phrases

**Describing the task**

- I'm **working on** the search feature.
- I'm **in the middle of** a big refactor.
- I'm **looking into** a performance issue. (*look into* = investigate)
- I'm **focusing on** the mobile app this week.

**Giving the reason**

- **The goal is to** make the page load faster.
- **It's for** the enterprise customers who need SSO.
- **This should help** support handle tickets faster.

**Describing progress**

- I'm **about halfway** done.
- **The main part is done**, but I still need to clean up the code.
- I'm **almost there**. I just need to fix one failing test.
- It's **taking longer than expected**, because the legacy code has no tests.

**Next steps**

- **Next, I'm going to** write the migration.
- **Once that's done**, I'll start on the dashboard.

## Common mistakes

**"I am work on the login page."**
After *am/is/are*, use the *-ing* form: *"I'm **working** on the login page."*

**"Currently I work on a bug in the payment flow."**
For a task happening now, use the present continuous: *"Currently I'm **working** on a bug in the payment flow."*

**"I'm working in the new API."**
We usually work **on** a project, feature or task: *"I'm working **on** the new API."* Use *in* for a language or place: *in Go, in the platform team.*

**"I finished the backend part yesterday, and I am doing the frontend part now since this morning."**
With *since*, use the present perfect continuous: *"…and I**'ve been doing** the frontend part since this morning."*

## Formal vs. casual

- **To your manager in a 1:1:** "I'm currently working on the CSV export. The backend is finished, and I expect to finish the UI by Thursday."
- **To a teammate in chat:** "Mostly the CSV export. Backend's done, doing the UI now."
- **In an interview:** "At the moment, I'm leading a migration from a monolith to microservices. The goal is to let teams deploy independently."

## Exercise

Think about the task you're working on this week. Write a short answer (4–5 sentences) to the question "What are you working on?" Include what the task is, why it matters, where you are and what's next.

Then write a one-line casual version for a teammate.

*Hint:* if you can't explain the "why" in one sentence, ask your product manager. That's a useful conversation too.

## Recap

- Use the present continuous for current tasks: *I'm working on…*
- Use the present simple for your general job: *I work on the payments team.*
- Answer with what, why, where you are, and what's next.
- Be specific about progress instead of saying "almost done".
- We work **on** a project or task.
